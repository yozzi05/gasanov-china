## Как работать с проектом
- `npm run dev` — разработка, `npm run build` — готовый сайт в папке `out/`
- `npm run images` — пересобрать картинки из `assets/originals` в `public/images`
- `npm run hanzi` — пересобрать контуры иероглифов (если добавится новый иероглиф — дописать его в `scripts/build-hanzi.mjs`)
- Весь текст, контакты и тарифы — в `src/content/site.ts`
