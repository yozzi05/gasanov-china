# G17-004 · Четыре станка для производства окон

Формат: видеоотзыв клиента + фото груза + скриншот сообщения
Категория: оборудование
Срок: 22 дня (со слов клиента в видео)
Услуги: консультации, выкуп, упаковка, доставка
[УТОЧНИТЬ: в тексте - станки для пластиковых окон, клиент в видео говорит «алюминиевых»]

## Задача
Клиенту нужно было выкупить и привезти из Китая четыре станка для производства окон.
Это был его первый заказ из Китая, поэтому переживаний было немало.

## Что сделали
Консультировали на каждом этапе, выкупили оборудование, надёжно упаковали каждое место
в защитную плёнку с маркировкой «хрупкое» и доставили всё в целости и сохранности.

## Результат
Станки доставлены за 22 дня. Клиент записал видеоотзыв у себя в цеху рядом
с уже установленным оборудованием.
